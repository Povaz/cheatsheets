Delete the recurrence

Sequence models in 2017 are recurrent: computation factors along symbol positions, each state built from the previous one. That inherently sequential nature precludes parallelization within a training example — long sequences train one step at a time no matter how many GPUs wait.

Attention (Bahdanau) had already given decoders a constant-length path to any source position — but always bolted onto an RNN. The paper's move: keep only the attention. The transformer is the first transduction model relying entirely on self-attention — attention relating positions of a single sequence to each other — with no recurrence and no convolution anywhere.

Scaled dot-product attention

The roles that were implicit in Bahdanau's alignment model get names and separate projections: a query is compared against keys, and the resulting weights mix the values. All comparisons happen at once, as matrix products:

The equation of the era Attention(Q, K, V) = softmax( Q·Kᵀ / √dₖ ) · V
  • Why dot-product scoring (vs Bahdanau's additive MLP): much faster and more space-efficient in practice — it runs as highly optimised matrix multiplication.
  • Why the √dₖ: at large dₖ the dot products grow large, pushing the softmax into regions of extremely small gradients — where additive attention used to win. Scaling removes that loss.

Multi-head attention

One attention over the full d_model averages everything into a single mix — and averaging inhibits attending to different things at once. Instead: project Q, K, V down h = 8 times with separate learned projections, attend in parallel, concatenate, project back.

  • Each head works in dₖ = dᵥ = d_model / h = 64 dimensions — so the total cost stays similar to one full-dimensional head.
  • The payoff: heads jointly attend to different representation subspaces at different positions — one head can track syntax while another tracks coreference.

The architecture: two stacks of blocks

Encoder and decoder are each N = 6 identical layers at width d_model = 512. Every sub-layer is wrapped the same way — LayerNorm(x + Sublayer(x)) — a residual shortcut plus normalisation, so signal and gradient always have a direct path through the stack.

Attention appears in three roles — same mechanism, different sources of Q, K, V:

  • Encoder self-attention — Q, K, V all from the previous encoder layer; every position sees every position.
  • Decoder masked self-attention — each position may attend only up to itself: illegal connections are set to −∞ before the softmax. With the outputs shifted right, prediction for position i can depend only on positions before i — this is what makes generation autoregressive.
  • Encoder–decoder attention — Q from the decoder, K, V from the encoder output: Bahdanau's alignment, in the new vocabulary.

The rest of the block

  • Position-wise feed-forward — the same two-layer network applied to every position independently: FFN(x) = max(0, x·W₁ + b₁)·W₂ + b₂, widening to d_ff = 2048 and back. Attention moves information between positions; the FFN transforms it at each position.
  • Shared embeddings — the input embedding, output embedding and pre-softmax linear layer share one weight matrix; in the embedding layers it is multiplied by √d_model.
  • Positional encoding — attention itself is order-blind, so position is added into the embeddings as fixed sinusoids: PE(pos, 2i) = sin(pos / 10000^(2i/d_model)), cosine on odd indices. Chosen because relative positions become easy to attend by, and sinusoids might extrapolate past training lengths — though learned position embeddings scored near-identically.

Why self-attention: the complexity argument

The paper's §4 compares a self-attention layer against the layers it replaces, on three axes:

Layer typeComplexity per layerSequential operationsMax path length
Self-attentionO(n² · d)O(1)O(1)
RecurrentO(n · d²)O(n)O(n)
ConvolutionalO(k · n · d²)O(1)O(log_k n)
  • O(1) sequential operations — the whole sequence computes in parallel; this is what recurrence could never give.
  • O(1) path length — any two positions connect in one hop, so long-range dependencies stop being a gradient marathon.
  • The n² is a bargain while sentences are short: self-attention is faster than recurrence whenever n < d — and 2017 sentences are far shorter than 512. (The n² bill comes due at LLM context lengths — a later Step's problem.)

Training and results

WMT 2014 translation. English→German: 4.5M sentence pairs, byte-pair encoding with a ~37k shared vocabulary. English→French: 36M sentences, 32k word-pieces. All runs on 8 P100 GPUs: the base model 100k steps ≈ 12 hours; the big model 300k steps ≈ 3.5 days. Adam (β₂ = 0.98) with the warm-up-then-decay schedule (4000 warm-up steps), dropout 0.1, label smoothing 0.1; decoding with beam 4, length penalty 0.6, averaged checkpoints.

  • En→Fr: state of the art at less than ¼ of the previous best model's training cost. The headline is the ratio, not the score: better translation for a fraction of the compute.
  • Not just translation: applied to English constituency parsing with minimal tuning, it stays competitive — the architecture generalises.

Where the Plan takes each piece

  • What survived from Bahdanau: the score → softmax → weighted-sum template, verbatim — only the score changed (additive MLP → scaled dot product) and the roles got explicit names (Q, K, V).
  • Step 3 keeps half the picture: GPT-style language models drop the encoder and the cross-attention — the decoder's masked self-attention block, stacked, is the whole model.
  • Step 4 replaces the parts: sinusoidal PE → RoPE, LayerNorm → RMSNorm, the ReLU FFN → SwiGLU, multi-head → MQA/GQA/MLA, and the exact attention computation → FlashAttention kernels. The block layout endures; every component named on this Sheet gets swapped.
