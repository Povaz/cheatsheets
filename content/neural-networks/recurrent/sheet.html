The problem with time

1990: feedforward networks handle patterns, but language, speech and action unfold in time. The obvious fix is a spatial metaphor — buffer the last N events into one long input vector (a shift register) and process it in parallel. Elman opens by dismantling it:

  • Someone must fill the buffer — and decide when its contents are ready to be examined.
  • The window is rigid — the input layer must fit the longest pattern, and every input must have the same length; hopeless for language, where phonemes and sentences alike vary.
  • Worst: absolute vs relative position — the same pattern shifted one step becomes a geometrically different vector; the similarity the network relies on is destroyed by a time shift.

His alternative: represent time implicitly, by the effect it has on processing — not as a dimension of the input. Concretely: give the network memory.

Context units: the simple recurrent network

Jordan (1986) had let a network see its own previous output through recurrent links — memory used to sequence actions. Elman's modification: feed back not the output but the hidden layer itself.

  • Context units = hidden state at t−1. One context unit per hidden unit; the copy-back connections are fixed at 1.0 and never trained — memory costs no parameters. Context starts at 0.5.
  • Trained with plain backpropagation — the context units look like just more inputs, so the 1986 machinery applies unchanged, one step at a time.
  • The hidden layer therefore does double duty: map input to output and keep whatever past matters. Its memory is task- and stimulus-dependent — the network learns what to remember; nothing marks time explicitly.

Three prediction experiments

Every simulation uses the same self-supervising task: predict the next input. The interesting results are what the network must discover to succeed.

  • Temporal XOR — a bit stream where every third bit is the XOR of the previous two, fed to a 1-input / 2-hidden / 2-context / 1-output net. The network learns to predict the predictable bits — XOR, sequentially, with two hidden units.
  • Letters → words — 200 sentences over a 15-word lexicon, concatenated into one unbroken letter stream. Prediction error peaks at the onset of each word and falls as the word unfolds — sequences bounded by high error are the words. A boundary cue nobody labelled, read straight off the error signal.
  • Words → lexical classes — 10,000 two- and three-word sentences over 29 words, 150 hidden units. Averaging the hidden state for each word and clustering the result reveals a hierarchy the input never encoded: verbs vs nouns; nouns → animates vs inanimates; animates → human vs nonhuman. Word meaning-classes emerge from word order alone.

What the paper actually proved

  • Prediction is free supervision. The teacher signal is just the next input — no labels, yet the error gradient forces the network to discover words, categories and structure. The straight line from here runs through RNNLM to next-token pretraining.
  • The hidden state is a learned representation of temporal context — not a buffer of raw history. Memory and processing are one mechanism, in the same units, bound together.
  • Why word2vec cites this: the RNNLM baseline in the word2vec paper is this architecture applied to language modelling — no projection layer, the recurrent hidden state supplying the short-term memory, cost H×H + H×V. What word2vec keeps is the lesson above: train representations by predicting neighbours.
